## Why

A loop that drives one shared live app cannot become a card today: its rules live in an untracked file a worktree never sees, and the repo's briefExtra forbids every worker the one thing the loop must do (read the live app). Both asks in #188 are about what a worker is told. The shape is additive: briefExtra stays a string, no adopter config changes, and the exception is visible on the verdict row.

## Done when

- A repo config key briefLocal (string, default "") names a file path, relative to the repo root or absolute; .claude-plugin/plugin.json, hooks/lib/init.ts (_briefLocal comment + empty default), hooks/lib/configtable.ts and hooks/lib/repoconfig.ts (REPO_KEYS, Effective, pick) carry it like briefTemplate. When the file exists at dispatch, its text up to the first `### allow:` heading is rendered into the brief right after {{extra}} under the exact heading `## Local rules (not for debrief)`; a missing file renders nothing; an unreadable or git-tracked file (git ls-files --error-unmatch says tracked) is refused with one line naming the path and why. The /delegation config table shows briefLocal.
- A card key `allow:` (a list of plain words, same rule as resources) is parsed in hooks/lib/card.ts and hooks/lib/dispatch.ts; the card tool accepts `allow` and writes it. For each id, the block under `### allow: <id>` in the briefLocal file (to the next `###` heading or end of file) is rendered into the brief after the local rules as `## Exception for this card: <id>` followed by the block text. An id with no block refuses the dispatch with one line naming the id and the file; `allow:` with no briefLocal set refuses likewise. The brief header gains `allow=<a,b>` after resources= when non-empty, and the verdict row carries ` allow=<a,b>` after the amended text when the brief header names any.
- The debrief never quotes the local section: hooks/templates/debrief.md tells the debrief to skip any brief section headed `## Local rules (not for debrief)` or `## Exception for this card:`, and hooks/lib/redact.ts drops any finding line that quotes text from such a section (a pure function given the brief texts, applied where redact runs on mod_findings). A pure test proves a finding quoting a local-rules line is dropped and a finding quoting the card title is kept.
- Tests: pure tests for the section split (text before the first ### allow:, each block by id, missing id), the render (heading text exact, order: extra, local rules, exceptions), and the allow list parsing; engine tests in tests/: a repo with briefLocal set and a card with allow: [live-reads] dispatches with both sections in the brief and `allow=live-reads` on the brief header and the verdict row; a card naming an unknown id is refused; a repo without briefLocal and a card with allow: is refused; a tracked briefLocal file is refused; no briefLocal and no allow: renders a brief byte-identical to today's. docs/configuration.md documents briefLocal (with the file shape: free text, then `### allow: <id>` blocks), docs/contracts.md documents the card key allow: and the brief/verdict allow= field, CHANGELOG Unreleased gets one entry naming #188. Wording generic: no product, repo, person, path or session names.

## Review

Attempt 1 (sonnet) accepted, with two disclosed amends: hooks/lib/brief.ts (allow added to BRIEF_FIELDS so allow= parses as its own header field) and hooks/lib/allow.ts (the exact `git -C <dir> ls-files --error-unmatch -- <path>` shape the tracked check runs). The red run fails the pure suite on the missing brieflocal module, allow on the card and dropLocalQuotes, and 4 of 6 new engine cases at base. hooks/lib/brieflocal.ts splits the file (rules before the first `### allow:`, blocks by id), renders the local rules and exceptions after briefExtra, and holds the four refusals (tracked, unreadable, unknown id, allow: with no briefLocal). The brief header carries allow=, and the verdict row ends with allow= after next=. The debrief template skips both sections, and redact.ts drops a finding that quotes a local line of 12 or more characters where the debrief findings are written. A brief with neither key is unchanged (renderLocal returns extra as is). Gates green: validate, node 1020/0, plugin 1533/0.
